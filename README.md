## 📦 快速开始

1. 将本目录放到 `data/plugins/deepwiki_plugin/`
2. 在 WebUI 中启用插件
3. 打开 **自定义命令 → 启用命令控制**
4. 发送命令：

```bash
/dw KiraAI
```

按提示用 `/dw 1` 选择仓库，或 `/dw owner/repo 你的问题` 直接查询。

---

## ⌨️ 命令用法

> 默认前缀 `/dw`，可在配置中自定义命令词。

| 命令 | 作用 |
|------|------|
| `/dw <关键词>` | 搜索候选仓库（**不会**自动绑定第一个） |
| `/dw 1` / `/dw 2` | 按序号选择候选并查询 |
| `/dw owner/repo` | 直接指定仓库（使用默认问题） |
| `/dw owner/repo <问题>` | 指定仓库 + 自定义问题 |
| `/dw <问题>` | 在**已有上下文**上继续追问 |
| `/dw ?` | 查看当前上下文仓库 |
| `/dw clear` | 清除上下文（预设仓库默认保留绑定，见下文） |

> **注意**：状态/清除词必须写在命令后面，即 **`/dw ?`**、**`/dw clear`**，而非单独的 `?` / `clear`。

### @ 唤醒

群聊中同样支持：

```bash
@安魂曲 /dw KiraAI
@安魂曲 /dw 1
```

会走命令路径，**不进入 LLM**。

## 📋 行为细节

### 1. 候选列表与操作说明

搜索后会列出候选，并附带选仓指引 —— `/dw 1` 选第一个、`/dw owner/repo` 直接指定、`/dw ?` / `/dw clear` 查看或清除上下文。

### 2. 下划线与代码保护

`sanitize` / `stylize` 会保护以下内容不被误处理：

- 代码块 `` ``` ... ``` ``
- 行内代码 `` `...` ``
- URL 链接
- **snake_case / 路径中的 `_` 一律保留**

`stylize` 样式：

- `## 标题` / `**粗体**` → `【标题】` / `【ＡＰＩ Ｋｅｙ】`

### 3. 引导语 / 操作指南使用 JSON

配置中用 `lines` 数组管理换行：

```json
{
  "lines": [
    "【DeepWiki 查询】",
    "仓库：{repo}",
    "问题：{question}",
    ""
  ]
}
```

支持的模板字段：`intro_template`、`forward_metadata_template`、`operation_guide_text`、`candidate_hint_text`。

### 4. 查询失败自动重置

若 DeepWiki 返回类似错误：

```
Repository not found. Visit https://deepwiki.com to index it.
```

插件会：① 提示失败原因 → ② **自动清除当前上下文** → ③ 提示重新 `/dw <关键词>` 或换 `owner/repo`。避免「选中坏仓库后，再发关键词却变成追问」的问题。

### 5. 切换项目

- 推荐：`/dw clear` → `/dw 新关键词`
- 无上下文时：直接 `/dw 新关键词` 会搜索
- 有上下文时：若输入像「单独关键词」也会重新搜索（启发式）；完整问句仍当追问

### 6. 预设仓库与重置

配置「默认初始仓库列表」（格式 `ctx;owner/repo`）后，对应会话/用户首次使用 `/dw` 会自动绑定预设仓库。`ctx` 支持完整 sid（`qq:gm:群号`）、忽略适配器名（`gm:群号`）、裸 ID（`群号`）、用户（`user:QQ`）——适配器名写错也能按「类型:ID」匹配上。

预设会话的行为：

- `/dw`（空参）：显示当前绑定的仓库与操作指南，而非通用用法
- `/dw <问题>`：直接向预设仓库提问（**单 token 如「安装」也按问题处理**，不会被误判成搜索）
- 想改查其他仓库：`/dw owner/repo` 显式指定

开启「上下文按用户隔离」时：`user:QQ` 专属预设优先；没有专属预设的用户，自动被所在会话的会话级预设接管。

默认开启「重置时保留预设仓库」：`/dw clear` 只清除对话记忆与候选列表，**仍保持绑定预设仓库**，可直接继续提问，不会回到搜索阶段。关闭该开关后，重置即彻底清空（下一次使用命令时预设会重新应用）。
